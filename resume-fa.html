خلاصه حرفه‌ای

توسعه‌دهنده فول‌استک با تجربه توسعه سامانه‌های سازمانی در هر دو حوزه بک‌اند و فرانت‌اند. در بک‌اند با C#، ASP.NET Core، طراحی API و معماری‌هایی مانند CQRS و DDD کار می‌کنم و در فرانت‌اند با React، Next.js و ابزارهای مدرن مدیریت داده و فرم‌ها قابلیت‌های کاربردی و قابل نگهداری توسعه می‌دهم. تجربه کار روی پلتفرم دژبان و سرویس مدیریت اسناد DCC را دارم.

۱۴۰۲ – آذر ۱۴۰۵
  • توسعه قابلیت‌های بک‌اند و فرانت‌اند پلتفرم سازمانی کنترل دسترسی با ASP.NET Core و React / Next.js
  • پیاده‌سازی سرویس‌ها و APIهای نسخه‌بندی‌شده و مشارکت در طراحی ساختار بک‌اند مبتنی بر CQRS و DDD
  • یکپارچه‌سازی پیام‌رسانی با MassTransit و RabbitMQ و پیاده‌سازی قابلیت‌های بلادرنگ با SignalR
  • توسعه رابط کاربری چنداپلیکیشنی با MUI و TanStack Query و مدیریت دسترسی مبتنی بر نقش
  • همکاری در استقرار مبتنی بر Docker و فرایندهای CI/CD با GitLab CI
توسعه‌دهنده بک‌اند — سرویس DCC برای پروژه بانک ملت
پروژه سازمانی
  • طراحی و توسعه سرویس مستقل Document Control Center با ASP.NET Core برای مدیریت متمرکز فایل‌ها و فراداده‌ها
  • پیاده‌سازی عملیات آپلود، دانلود، حذف نرم، بازیابی فایل و حذف دائمی از طریق REST API
  • ساختاردهی قابلیت‌ها با CQRS، MediatR و الگوی Vertical Slice و اعتبارسنجی درخواست‌ها با FluentValidation
  • ذخیره فراداده‌ها در PostgreSQL با EF Core و پیاده‌سازی ذخیره‌سازی فایل از طریق انتزاع IFileStorage
  • یکپارچه‌سازی با سرویس‌های دیگر از طریق HTTP و استفاده از JWT، کنترل دسترسی و زیرساخت MassTransit Outbox/Inbox
